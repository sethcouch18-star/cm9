# Colormons 4.0 (Cobblemon 1.8.1, NeoForge 1.21.1)

Look at a Pokemon and press C (rebind in Options > Controls if C is taken).

Four groups: Primary, Secondary, Tertiary, Custom. The first three are the biggest
colours in the texture; Custom starts empty and is filled with the Edit brush.

- Hover a group button to see that group picked out on the mini map beside it.
- Edit toggles paint mode: click the pixel grid to move pixels into Custom.
- Finishes: Default, Glossy, Matte, Shiny.
- The preview panel draws the real Pokemon, so your changes show instantly.
- Colours are sent to the server and relayed, so every player sees them.

Config: config/colormons.json
Masks: assets/colormons/masks/<species>.png (red Primary, green Secondary, blue Tertiary, yellow Custom)
